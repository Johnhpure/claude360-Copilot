# P1-4 白牌化文案分类（Kun / DeepSeek 残留说明）

> 依据 Codex 审计 P1-4「只替换用户可见主路径文案，保留内部/隐藏入口」要求，对
> `src/renderer/src/locales/{zh,en}/{common,settings}.json` 中的 `Kun` / `DeepSeek`
> 命中逐项分类。已替换主路径与同类可见 App 文案；以下为**有意保留**项及原因。

## 已替换（主路径 + 同类可见 App 文案）

- `runtimeStatusRestarting/RestartingAttempt/Crashed/Failed`、`runtimeOffline`、
  `runtimeFetchFailed/ModelRequestFailed/BinaryNotInstalled/MissingApiKey/AutoStartDisabled`、
  `runtimeOfflineHeroTitle/Sub`：运行时生命周期状态/离线错误横幅。
- `toolCatalogChangedStatus`、`toolStormSuppressedStatus`、`compactionSummaryFallbackStatus`：
  与上面同一状态横幅表面的运行时状态。
- `planToolResultMissing`、`writeImageRestartRequired`、
  `sidebarWorkspaceRemoveDialogDescription`、`sidebarThreadDeleteDialogDescription`：可见错误/确认弹窗。
- settings：`desktopOpenAtLoginDesc`（开机启动）、`apiKey`/`writeApiKey`（DeepSeek→Claude360 API Key）、
  `baseUrlDesc`/`baseUrlSharedDesc`（默认地址描述 DeepSeek→Claude360）。
- `kun serve` 字面命令保留，但周边品牌词已改 Claude360 Copilot，并注明这是「本地运行时命令」。

## 有意保留（记录原因）

| 键（前缀/示例） | 类别 | 保留原因 |
| --- | --- | --- |
| `claw*`（clawCoreTitle、clawDeepseekSubtitle、clawTaskStarted、clawTelegramConnectedHint 等） | 隐藏入口 | 微信/IM 手机连接为隐藏入口特性，审计明确允许保留。 |
| `pluginOAuth*`、`pluginMcpGuiScheduleTitle` | 隐藏入口 | MCP OAuth/插件为隐藏高级入口，审计允许保留。 |
| `workflowModelEmptyHint` | 隐藏入口 | workflow 文案，审计允许保留。 |
| `usageHeatmap*`（badge/sub/grid/empty/loading 等） | 独立功能面板 | 用量热力图为自包含面板；建议后续单独批量白牌化，非本轮主路径。 |
| `focusModeToggleTitle`（“关闭 Kun 动画”） | 保留品牌资产 | 指 Kun 吉祥物动画（`KunStateFigure`/`KunHeroStage` 为运行时保留名）。 |
| `cursorSpotlightColorDesc`（“Kun 当前柔和蓝色”） | 装饰/文案 | 仅描述默认高光色，非功能主路径。 |
| `providerModelMaxOutputHint`（“Kun 运行时默认值”）、`designQualityHint`、`mediaGenerationDesc` | 技术描述 | 指本地运行时行为，非品牌暴露主路径。 |
| `legacyImportDesc`（“以前 DeepSeek GUI 安装”） | 事实性迁移源 | 描述从旧 DeepSeek GUI 安装导入，是事实来源，改名会失真。 |
| `providerModelReasoningProtocolDeepseek`（“DeepSeek 风格”） | 协议名 | reasoning_effort 协议风格名，技术术语。 |
| `kunBaseUrlOfficial`、`firstRunBuyApiHint`、`baseUrlPlaceholder`、`kunModelContextProfileDesc`、`kunCompactionThresholdsDesc` | 事实性上游/模型 | DeepSeek 作为实际上游供应商 / DeepSeek V4 模型名 / 官方示例 URL，均为事实引用。 |
| `conversationWorkspaceRootPlaceholder`（`~/Documents/Kun`） | 路径默认值 | 与运行时目录约定一致的默认路径占位，属内部保留。 |
| `computerUseRestartHint`（“完全退出 Kun”） | 可后续处理 | 可见重启提示；本轮保留，建议下轮与其余可见项统一处理。 |

## 内部保留边界（不改，代码/运行时）

`window.kunGui`、`kun-runtime`、`KUN_*`、`AgentKun`、`KunStateFigure`、`KunHeroStage`、
`kun_*.png`、R2 release 前缀、legacy migration 常量、`kun serve` 命令本体。
