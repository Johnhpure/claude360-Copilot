# P0 白牌化实施计划（消除一切可识别的 "Kun" 痕迹）

> **For agentic workers:** REQUIRED SUB-SKILL: 用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐 Task 实施。步骤用 `- [ ]` 复选框跟踪。

**Goal:** 在不破坏功能的前提下，把客户端的所有用户可见 / 文件系统·进程可见 / DevTools·抓包可见的 "Kun" 品牌痕迹替换为 "Claude360 Copilot"（中性/品牌命名），使普通用户与会抓包的技术用户都识别不出这是 Kun 二开。

**Architecture:** 纯机械替换 + 文本中性化，零业务逻辑变更。以「命名映射表」为唯一事实源；按"可见层级 + 风险"切分 Task；每个 Task 用 `rg` 精确定位、`Edit`/`sed` 替换，用 `npm run typecheck` + `npm run build` + `npm test` + `rg` 残留自查兜底。**不含任何 git 操作**（提交由用户决定）。

**Tech Stack:** Electron 34 + React 19 + TypeScript（双 tsconfig）+ Vite（electron-vite）+ Vitest + electron-builder。

**前置依赖：** 本计划假定 **M1 的 P2（移除形象工坊）已先行完成**（D5 顺序为 P2→P0）。因此 `ikun*` 彩蛋、`KunCelebration*`、`SidebarMascot`、`ui-plugin`、`easter-egg` 相关文件/文案/CSS **已不存在**，本计划不涉及它们；`ds-ikun-*` / `ds-kun-celebration-*` 等 CSS 亦随 P2 移除。若执行 P0 时 P2 尚未完成，先跑 P2。

**保留边界（D7，确认不改）：** `kun/` 运行时**目录名**、`KUN_*` 环境变量（renderer `process.env.KUN_` 命中 0，已验证）、`src/shared/kun-endpoints.ts` 的 `KUN_*_TEMPLATE` 路径常量、跨包 `import '../../kun/src/...'` 路径、运行时 provider `id = 'kun'`（内部标识，不出网、界面用 `displayName` 展示）、`AgentKun`/`KunStateFigure`/`KunHeroStage`（P2 保留的形象/工作态组件）。`ds-` CSS 前缀（6028 处，非 "kun" 字样、属 DeepSeek 遗留缩写）**不在 P0 范围**，列为可选独立任务。`Kun*` TypeScript 类型名（编译后不出网、DevTools 不可见）默认保留，列为可选后续。
