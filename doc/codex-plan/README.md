# Codex Plan 文档区

本目录仅存放 Codex 生成的 Claude360 Copilot 二次开发相关规划文档。

约定：

- 不修改上级 `doc/` 目录中 Claude Code 正在维护的编号文档。
- 任务拆解文档放在本目录，文件名使用 `task-*.md`。
- 开发设计文档放在本目录，文件名使用 `dev-*.md`。
- 可执行实施计划放在本目录，文件名使用 `plan-*.md`。
- 阶段性决策、风险和待确认问题统一记录在对应文档末尾。
- 未经明确要求，不在文档阶段执行代码开发、生产环境操作或 git 提交。

当前 Codex 计划：

- `plan-index-claude360-copilot-phase1.md`：第一阶段实施计划总索引。
- `plan-01-newapi-cli-auth-token-stats.md`：newapi CLI 登录与 token 用量接口。
- `plan-02-copilot-claude360-account-core.md`：客户端 Claude360 账号、密钥和登录核心。
- `plan-03-copilot-models-my-page.md`：模型收口、API Key 分组和“我的”页。
- `plan-04-copilot-brand-route-hide.md`：品牌、appId、路由入口和小鸟功能隐藏。
- `plan-05-copilot-native-music.md`：原生音乐工作台。
- `plan-06-copilot-native-canvas.md`：原生生图工作台 MVP。
